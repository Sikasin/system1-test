# システム1を使って画像解析してみた（体験ページ）

ブラウザの中で動く、物体検出の体験ページです。

人の判断には「パッと見て分かる」速い働き（システム1）があります。このページは、その働きをAIで真似たものです。カメラの映像やサンプル画像を見て、「何が写っているか」をその場で言い当てます。

## 使い方

- **カメラではじめる**：端末のカメラ映像で判定します
- **デモで見る（カメラなし）**：サンプル画像で試せます

画面には、検出にかかった時間（ミリ秒）、見つけた物の数、1秒あたりの検出回数を表示します。見つけた物は日本語の名前と確信度（％）で出ます。

## 仕組み

- TensorFlow.js と COCO-SSD（lite_mobilenet_v2）をブラウザの中で実行しています
- **映像はあなたの端末の中だけで処理され、外部に送信されることはありません**
- ページの閲覧数だけを、プライバシーに配慮した方法で数えています（GoatCounter）

## これは何の体験ページか

歩行アシストアプリ（白杖の先を見るアプリ）の開発記録の一部です。歩行アシストの「目」にあたる画像解析の働きを、触って確かめられるように切り出しました。
